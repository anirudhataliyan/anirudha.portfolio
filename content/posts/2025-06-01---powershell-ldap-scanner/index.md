A PowerShell-based Active Directory assessment tool that automates LDAP enumeration and security checks. It includes checks for common Active Directory relay attack exposure and exports results to help with quick internal security evaluation.

It was built to make the initial discovery and validation process easier when working within AD environments, especially during testing and assessment workflows.
